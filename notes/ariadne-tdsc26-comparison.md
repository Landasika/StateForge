# Ariadne(TDSC 2026)对照分析 —— 重叠与差异(2026-09-20)

> 对象:Peng, Zhang, Mu, He, Ji, Wan, Zhao, "Ariadne: Reconstruction of Stateful Web
> Attacks via Goal-Oriented State Search", IEEE TDSC 23(5), Sep-Oct 2026, pp.11184-11198,
> DOI 10.1109/TDSC.2026.3711370。全文付费墙(摘要+元数据级精读;全文项标 ⚠️待读)。

## 1. Ariadne 是什么(按摘要)

- **场景**:IDS/SIEM 在**带载荷的终末请求**上报警后,从海量噪声流量日志里
  **重建完整攻击链**(前置的状态准备请求序列)——做**根因分析/取证**。
- **输入**:**已知的终末攻击请求**(检测已发生,攻击已成功)。
- **机制**:目标导向状态空间搜索;从终末请求**推导目标后端状态**;用基于
  **二部图匹配**的状态距离度量导航;数据驱动的 API 依赖 + 状态感知的参数寻源。
- **结果**:15 个真实漏洞,链长至 8 步、20 分钟内全重建;SOTA 基线在 >2 步的
  攻击上全失败。

## 2. 重叠与差异总表

| 维度 | Ariadne | 本项目(Keysmith/StateForge) | 判定 |
|---|---|---|---|
| **目的** | **事后取证**:攻击已检出,重建链做根因 | **事前发现**:找没人报过的漏洞 | ✅ 正交(互补非竞争) |
| **先验输入** | 必须给定终末攻击请求 + 攻击载荷 | **零先验**(新状态前沿为罗盘,v2.1 核心) | ✅ 本质差异 |
| **问题方向** | 从终末请求**反推**前置链(解释已发生) | 从状态前沿**正向构造**到达链(制造未发生) | ✅ 不同问题 |
| **状态来源** | **数据驱动**(流量日志学 API 依赖)⚠️待读细节 | **源码恢复**(静态+LLM 语义提升) | ✅ 知识来源不同 |
| **搜索机制** | 目标导向 + **状态距离**(二部图匹配) | 目标导向 + 状态距离(SSTG 图距离) | ⚠️ **真重叠**:机制同族,须引用并差异化度量 |
| **反向链构造** | 有(重建前置序列) | 有(反向 BFS + 拓扑序) | ⚠️ 同族,差异化点=底座(源码图 vs 数据依赖) |
| **fuzz/探索** | 无(非 fuzzer,无覆盖/变异/探索环) | 有(状态新颖度反馈、参数变异、能量调度) | ✅ 我们独有 |
| **快照/状态重置** | 无(重放验证用副本)⚠️待读 | 有(fork COW+L2,epoch 语义,调度消融) | ✅ 我们独有 |
| **LLM** | 无 | 有(候选锚定语义提升+修理) | ✅ 我们独有 |
| **oracle/判定** | 无检测职责(攻击已知) | ANOTA 注解=oracle+目标定义 | ✅ 不同 |
| **评测靶** | 15 个真实漏洞(CVE 类)⚠️待读 | vulnshop/VAmPI/DSVW/PyGoat | 参考 |

## 3. 战略结论

1. **威胁降级:从"同题竞争"降为"机制近亲+问题互补"**。它做"攻击发生后解释
   链",我们做"攻击发生前发现链"。论文里定位为 **complementary**:
   "Ariadne 重建已发生攻击的前置链(取证);Keysmith 构造未发生攻击的到达链
   (发现)——二者共享'深层状态链难'的问题意识,但输入假设相反。"
2. **必须引用并差异化的一处**:目标导向状态搜索 + 状态距离导航(同族机制)。
   差异化写法:Ariadne 的状态模型与距离来自**运行时数据**(流量/依赖学习),
   我们来自**源码恢复的 SSTG+锚点**(含 LLM 语义),且距离服务的是
   exploit/explore 双臂与能量调度,不止搜索。
3. **白捡的动机弹药**:">2 步的攻击,SOTA 基线全失败"(他们实测)直接支撑
   我们"深层状态链是公认难点"的 motivation;15 真实漏洞/8 步链也是
   chain-depth 量级的旁证。
4. **时间压力重估**:不必恐慌,但 TDSC'26 已把"状态化 Web 攻击链"合法化为
   期刊级课题——**发现侧(我们)的空白窗口仍在,但不会永远开**。
