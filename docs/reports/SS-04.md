## 运行时观测

- `SessionSnapshotView` 固化观察点：`client_id`、`observation_point`、
  `observed_at`、`status`。
- 只读适配：目标的 `observe_session()` 从客户端 Cookie Jar 解码签名
  Cookie；不建请求上下文、不触发路由、不修改 Cookie Jar。
- 三值：
  - `decoded` / `absent` 才可判定存在/不存在；
  - `invalid` / `unknown` → `UNKNOWN`，不降级成“空会话”。
- `StateObservation` 使用 `StateKey("Session.<key>", entity=client_id,
  scope=session)`；`observed_value` 保留裸值，`value_kind` 区分
  `NUMBER/STRING/BOOLEAN/NULL/MISSING/UNKNOWN`。
- `evaluate_session_condition(s)` 支持 EXISTS / NOT_EXISTS / TRUTHY /
  FALSY / EQ / NE / IN / NOT_IN；条件组是 AND；False/Unknown 不升级为
  verified。
- `SessionRuntimeObserver` 实现既有 `RuntimeObserver` 协议，可被
  `observer_from_module` / `ExecutionParameters` 直接发现，并写入
  `StateEvidenceLedger` 的 verified 桶。

## 检查点与重放

- `SessionReplayCheckpoint`：
  - 只由 `status=VERIFIED` 且有 Session witness 的 guided result 创建；
  - 保存 verified 前缀、条件组、观测值、writer 块、证据；
  - C10 采用直接请求 steps，复用 `encode_sequence_seed`；
  - `prefix_len` 支持“verified 前缀 + 后缀”结构。
- `replay_session_checkpoint`：
  - 先 `reset_hook()` 冷启动（新客户端）；
  - 重放前缀，重新读 Cookie Jar，重新判定条件组；
  - 后缀在前缀之后执行并独立判定；
  - 目标覆盖但条件不成立 → `TARGET_ONLY`，不是成功；
  - 观测失败 → `UNKNOWN`，不是成功。
- `suffix_without_prefix_reaches_target` 作为隔离对照：后缀单独执行
  不得借用前缀会话。
- `inject_session_checkpoint_seed` 只把 verified 前缀写成 C10 种子，
  内容哈希去重。

```bash
python -m pytest stateforge/tests/state/test_session_observation.py \
  stateforge/tests/state/test_session_replay.py \
  stateforge/tests/state/test_session_isolation.py \
  stateforge/tests/targets/session_gate -q
```

结果：`40 passed`（新增 26 + SS-00 靶 14）。

覆盖：

- decoded/absent/invalid/unknown 三值；
- NULL vs MISSING vs UNKNOWN；
- TRUTHY/FALSY、EQ/NE、IN/NOT_IN；
- 观测绑定 client/observation point，跨 client 不合并；
- 观测器只读、不触发路由；
- 无 witness 不能建检查点；
- 检查点 round-trip/C10；
- 冷启动重放、重复重放；
- 错误条件 → `TARGET_ONLY`，不假成功；
- 缺前缀 → 不达目标、不假成功；
- 后缀在 prefix 后可达，单独执行不可达；
- 观测 UNKNOWN 不升级；
- 种子注入去重。

## 边界

- 当前 verified 观测针对 Flask 默认签名 Cookie Session；其他后端
  （JWT/服务端 Session）需要新的 observer，不得复用本适配器冒充。
- `absent` 只在该观察点/该客户端内是权威“无 Cookie”；不能跨 client
  推断。
- 检查点是 Session 域包装，复用 `StateEvidenceLedger`、C10、reset
  lifecycle；没有复制 ledger。
