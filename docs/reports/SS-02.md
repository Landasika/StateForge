## 范围与实现

- `SessionAccessIndex`：按 `CONST/SYMBOLIC/ANY/UNKNOWN` 分桶保存
  readers/writers/deleters；`writers_of(reader)` 逐 reader 查询，
  不生成全图 writer×reader 笛卡尔积。
- `SessionDependency`：`writer_site_id`、`reader_site_id`、
  `writer_block/reader_block`、`key_overlap`（MUST/MAY/DISJOINT）、
  `client_binding`、`candidate_effect`、`evidence`、`priority`。
- `query_session_frontier(ir, index, target_block)`：
  - 复用现有 `goal_derivation._intra_adjacency` 的函数内投影（含
    callsite/returnsite），从 entry 枚举简单路径到目标块；
  - 每条路径保留一组 `SessionCondition`，不把互斥分支 AND 成一个条件；
  - 识别 `is None` / `==` / `!=` / `in` / `not in` / truthy / falsy，
    以及局部别名 `uid = session.get('uid')`；
  - 无法解析的守卫进入 `unresolved`，并置 `partial=True`，不猜测；
  - `clear()` 作为 ANY 候选写入出现；对 `uid == 7` 不是满足者，对
    `uid 不存在` 是候选；
  - 只写 `other` 的写入块不会匹配 `uid` 条件；
  - 静态无法证明同一客户端时统一携带
    `writer.?client == reader.?client` 约束；
  - 所有依赖 `STATIC_MAY`，不冒充 verified。
- `SessionCondition.from_dict()` 供 SS-04 检查点重放复用。

## 测试

```bash
python -m pytest stateforge/tests/state/test_session_index.py \
  stateforge/tests/state/test_session_goal_query.py -q
```

结果：`13 passed`（索引/查询 10，目标查询契约 3）。

覆盖：

- `/protected` 目标反查到 `authenticate` 的 `uid=7` 写入块；
- `logout` 的 `pop(uid)` 与 `clear()` 作为破坏/不存在候选；
- `other` 写入不被错误匹配；
- 动态 key 为 MAY 而非 MUST；
- `NOT_EXISTS` 时 DELETE/CLEAR 优先于 SET；
- 两条互斥路径保留为两个条件组，不合并；
- 分支歧义别名降级为 `KEY_UNKNOWN`，不取第一个 key；
- 非 Session 守卫 unresolved/partial；
- 查询确定性、`to_dict` 不含 verified 声明。

## 边界

- `partial=True` 表示静态路径/客户端约束未完全证明，不是失败。
- 不证明运行时 client 身份；同客户端是约束，不是事实。
- 本批不做运行时观测、不写检查点。
