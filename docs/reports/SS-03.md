## 范围与实现

- 保持 Atheris 为唯一变异/执行引擎；本模块是**有界种子生产者**：
  - 可在测试中直接调用；
  - 可在 `entry_driver --session-guided` 启动前搜索一次，把有效
    C10 序列写入语料，再进入 `atheris.Setup`。
- 输入池只允许独立单请求 dict；包含 `steps` 的池项直接拒绝。
- 结构变异：追加、替换末步、删除步、参数值微变；不预置完整
  `login → profile` 顺序。
- 评分：目标块 Trace 覆盖 > writer 块覆盖（仅进展）+ 距离 +
  verified 结果 - 步数惩罚；`guided=False` 为同池消融，忽略 writer
  覆盖，不改变请求空间。
- 预算与去重：固定 seed、`max_steps`、`max_execs`；规范化序列哈希
  含目标/基线/参数/步序，重复不执行。
- 每次候选从 `reset_hook()` 干净客户端开始；候选内多步共享 Cookie
  Jar；候选之间隔离。
- 判定：
  - 无可靠 probe：目标覆盖只报 `PROXY_PROGRESS`，不生成
    verified checkpoint；
  - 有 probe 且 Session 条件组满足：`VERIFIED`，才允许检查点。
- 输出每次尝试的 C10 steps、Trace span、覆盖块、writer 块、距离、
  得分、错误与状态；发现序列用 `encode_sequence_seed` 落盘。
- CLI 新开关默认关闭，不改变 A–F/默认实验行为。
